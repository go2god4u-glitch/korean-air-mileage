# 마일리지로 떠나는 날

[![Windows·macOS 자동 검사](https://github.com/we-insub/Korean_air/actions/workflows/test.yml/badge.svg)](https://github.com/we-insub/Korean_air/actions/workflows/test.yml)

**원하는 노선과 좌석 등급에 보너스 좌석 표시가 있는 날짜를 모아보는 개인용 로컬 프로그램**입니다. 대한항공·아시아나는 공개 월별 달력을 읽고, SAS·스카이팀·스타얼라이언스는 조회용 Chrome에서 공식 검색을 날짜별로 진행합니다.

조회 결과에서 날짜를 고르면 새 Chrome 창의 대한항공 보너스 좌석 달력에 노선과 날짜를 자동으로 입력해 줍니다. 로그인이나 API 키 없이 공개 조회 화면을 이용합니다.

> 대한항공의 공식 서비스가 아닙니다. 조회 결과는 대한항공이 공개한 기준 시각의 현황이며, 실시간 예약 가능 여부나 정확한 잔여 좌석 수를 뜻하지 않습니다.

## 이 저장소에서 추가한 기능

원본(we-insub/Korean_air)은 노선 하나씩 조회하는 도구입니다. 여기에 다섯 가지를 더했습니다.

- **비즈니스 이상 타기** 탭 — 목적지를 정하지 않고 대륙 단위로 훑어 비즈니스·일등석 자리를 찾습니다. 비행시간 필터와 귀국편(해외→인천) 방향을 지원합니다.
- **자동 알림 신청** 탭 — 노선과 날짜를 등록하면 GitHub Actions가 **매시간** 대신 조회하고, 새 자리가 열리면 텔레그램으로 알립니다. 이 컴퓨터가 꺼져 있어도 동작합니다.
- **일등석 분리 표시** — 대한항공이 보너스와 좌석승급을 한 표시로 묶어 공개하므로, "둘 중 하나"로 표기합니다.
- **실시간 재확인** — 공개 달력은 하루 한 번 만들어지는 스냅샷이라 이미 팔린 자리가 남아 있습니다. 찾은 날짜를 항공사 예매 시스템에 다시 물어 **매진된 건 결과에서 뺍니다**. 항공사 로그인이 필요합니다.
- **9시 예매 대기 (오픈런)** — 두 항공사 모두 매일 **09:00에 예매 범위의 마지막 날짜**를 엽니다 (대한항공 360일 뒤 · 아시아나 364일 뒤). 타려는 날짜를 신청해두면 그 시각에 맞춰 대기하다가 **좌석 선택까지 끝낸 예매 화면**을 띄웁니다. 결제는 직접 하시면 됩니다.

조회는 모두 창 없이(headless) 실행됩니다. 아시아나는 클라우드 IP가 차단되어 **로컬에서만** 조회됩니다.

> **결제는 자동화하지 않습니다.** 좌석 선택까지만 하고 멈춥니다. 마일리지가 차감되고 현금(유류할증료·세금)이 청구되는 마지막 버튼은 직접 누르셔야 합니다. 비밀번호도 저장하거나 입력하지 않으며, 항공사 로그인은 조회용 Chrome에서 직접 하시면 그 세션만 사용합니다.

## 주요 기능

- 출발·도착 공항, 편도·왕복, 조회할 월, 좌석 등급 선택(전체 포함)
- 대한항공 공식 보너스 조회 화면의 공항 목록에서 도시를 선택하거나 도시명·공항 코드로 검색
- 일반석·프리미엄석·비즈니스(프레스티지석)의 **보너스 좌석** 날짜만 표시
- 왕복의 가는 날·오는 날 선택과 최소 여행 기간에 따른 날짜 필터
- 선택한 조건을 대한항공 공개 달력에 자동 입력
- 이전 조회 결과 저장, 기준 시각 표시, 최근 결과 재사용
- SAS 조회용 Chrome 로그인, 날짜별 병렬 검색으로 월별 결과 표시, 로컬 SQLite 저장(실험적 기능)
- 아시아나 공개 월별 달력과 스카이팀·스타얼라이언스 검색 결과 수집(실험적 기능)

대한항공·아시아나 공개 달력에서는 좌석 승급 표시를 제외합니다. 지원 등급은 프로그램별로 다르며, 아시아나 공개 달력은 일반석·비즈니스석을 제공합니다.

## 프로그램별 지원 범위

| 프로그램 | 이 프로그램에서 하는 일 | 실제 좌석 확인 |
| --- | --- | --- |
| 대한항공 스카이패스 | 공개 보너스 좌석 달력을 조회하고 저장된 결과를 다시 보여 줍니다. | 이 프로그램의 결과와 대한항공 공식 화면 |
| SAS 유로보너스 | 로그인 후 선택한 월을 최대 6개 날짜씩 동시 검색. 왕복은 방향별 편도 검색. | 항공편·등급·포인트·조회 시각 |
| 아시아나클럽 | 로그인 없이 월별 공개 달력 조회. 왕복은 양방향 달력 조회. | 일반석·비즈니스 보너스 표시와 공개 기준 시각 |
| 스카이팀 · 대한항공 마일리지 | 대한항공과 같은 조회용 Chrome 로그인 사용. 왕복 조건으로 날짜별 검색. | 기준 상대 날짜와 항공편을 명시한 조건부 결과 |
| 스타얼라이언스 · 아시아나 마일리지 | 아시아나 로그인 후 날짜별 검색. 왕복은 방향별 검색. | 공식 검색에 표시된 등급별 항공편 |

**스카이팀 월별 검색에는 제한이 있습니다.** 공식 사이트는 가는 항공편을 선택해야 오는 편을 보여줍니다. 가는 달 조회에서는 오는 달 마지막 유효 날짜를 고정하고, 오는 달 조회에서는 가는 달 첫 유효 날짜의 첫 항공편을 기준으로 검색합니다. 모든 왕복 날짜·항공편 조합을 조회한 결과는 아닙니다. 대한항공 스카이팀은 왕복 조건으로 검색합니다.

같은 제휴 항공편도 사용하는 마일리지 프로그램에 따라 좌석과 필요 마일리지가 다를 수 있습니다. 각 방향에 좌석이 표시되어도 특정 왕복 조합의 예약을 보장하지 않습니다.

## 실행 환경

| 항목 | 필요 조건 |
| --- | --- |
| 운영체제 | Windows 11 이상 또는 macOS 14 이상. Linux는 미검증 |
| Python | 3.8 이상, 새로 설치한다면 3.11 이상 권장 |
| Node.js | 22 이상, npm 포함 |
| 브라우저 | Google Chrome 설치 필요 |

별도 Python 패키지나 데이터베이스 서버, `.env` 설정은 필요하지 않습니다. SAS 결과는 Python 내장 SQLite로 로컬에 저장합니다. **Node.js용 Playwright는 `npm ci`에 포함되어 설치됩니다.** Google Chrome은 별도로 설치되어 있어야 합니다. 운영체제 기준은 [Playwright의 공식 실행 환경](https://playwright.dev/docs/intro#system-requirements)을 따릅니다.

## 빠른 시작

### 1. 프로젝트 받기

GitHub의 **Code → Download ZIP**으로 내려받아 압축을 풀거나, 이 저장소를 클론합니다. 터미널에서 `package.json`과 `local_app.py`가 있는 프로젝트 폴더로 이동하세요.

### 2. Windows에서 설치하고 실행하기

먼저 [Python](https://www.python.org/downloads/windows/), [Node.js](https://nodejs.org/en/download), [Google Chrome](https://www.google.com/chrome/)을 설치합니다. Python 설치 과정에 **Add python.exe to PATH** 항목이 있으면 선택하세요.

1. 압축을 푼 프로젝트 폴더에서 **`setup-windows.bat`를 더블클릭**합니다.
2. Playwright를 포함한 의존성 설치와 실행 환경 확인이 끝날 때까지 기다립니다.
3. **`start-windows.bat`를 더블클릭**하면 로컬 조회 화면이 열립니다.

다음부터는 `start-windows.bat`만 실행하면 됩니다. 설치된 프로그램을 찾지 못하면 설치를 마친 뒤 실행 창을 새로 열어 주세요.

PowerShell에서 직접 실행하려면 프로젝트 폴더에서 다음 명령을 사용합니다. `python` 대신 `py -3`를 사용해도 됩니다.

```powershell
npm.cmd ci
npm.cmd run doctor
python local_app.py --open
```

### 3. macOS에서 설치하고 실행하기

프로젝트 폴더에서 다음 명령을 실행합니다.

```sh
npm ci
npm run doctor
python3 local_app.py --open
```

브라우저에 [로컬 조회 화면](http://127.0.0.1:8765/)이 열립니다. 자동으로 열리지 않으면 이 주소를 직접 열어 주세요. 사용하는 동안 터미널을 열어 두고, 종료할 때는 터미널에서 `Ctrl+C`를 누릅니다.

다음 실행부터는 `npm ci`를 다시 실행할 필요 없이 아래 명령만 사용하면 됩니다. 의존성이 변경된 버전을 받은 경우에는 `npm ci`를 다시 실행하세요.

```sh
python3 local_app.py --open
```

macOS에서는 최초 설치 후 **`마일리지 조회.command`를 더블클릭**해도 됩니다. 더블클릭 실행이 되지 않으면 위 터미널 명령을 사용하세요.

### 4. 마일리지 좌석 조회하기

1. 출발·도착 공항의 목록 버튼을 눌러 도시를 고릅니다. `인천`, `싱가포르`, `ICN`, `SIN`처럼 도시명이나 공항 코드로 검색해 선택해도 됩니다.
2. 편도·왕복, 조회할 월, 좌석 등급을 선택합니다.
3. **마일리지 좌석 조회**를 누릅니다.
4. 결과에서 원하는 날짜를 고릅니다. 왕복은 가는 날과 오는 날을 모두 선택합니다.
5. **선택한 날짜로 대한항공 열기**를 누르면 새 Chrome 창에 선택한 조건이 자동 입력됩니다.

**처음 설치한 상태에는 저장된 조회 결과가 없습니다.** 화면을 열거나 조건을 바꾸는 것만으로 새 조회가 시작되지는 않으므로, 처음에는 조회 버튼을 눌러 주세요.

도시 목록에는 2026년 9월 7일 대한항공 보너스 조회 화면에서 확인한 **8개 지역·117개 공항**을 미리 담았습니다. 공항 목록에 있다는 것이 특정 노선의 운항이나 좌석을 보장하지는 않습니다. 목록은 프로젝트에 포함되어 있으며, 목록을 열거나 검색할 때 항공사에 접속하지 않습니다. 공항 코드 세 글자를 직접 입력할 수도 있습니다. [목록의 출처와 갱신 방법](config/README.md)

가는 달·오는 달은 **연도별로 구분된 월 목록**에서 선택합니다. 다음 해의 월도 같은 목록에 있으며, 현재 조회 가능한 기간은 입력란 아래에 표시합니다. 왕복의 오는 달은 가는 달보다 앞선 월을 선택할 수 없습니다.

좌석 등급에서 **전체**를 고르면 일반석·프리미엄석·비즈니스 중 하나라도 보너스 좌석 표시가 있는 날짜를 보여줍니다. 날짜 카드에 표시가 있는 등급을 함께 적으며, 같은 날짜는 한 번만 셉니다. 일등석과 좌석 승급 표시는 제외합니다. 기존 조회 결과가 있으면 전체로 바꿔도 그 결과를 그대로 활용합니다.

공항 코드 예시, 왕복 선택, 오류 해결은 **[자세한 사용법](docs/usage.md)**에서 확인할 수 있습니다.

### Playwright도 따로 설치해야 하나요?

`setup-windows.bat` 또는 `npm ci`가 프로젝트에 지정된 Playwright와 실행 도구를 함께 설치합니다. Python용 `pip install playwright`는 필요하지 않습니다.

이 프로그램은 설치된 **Google Chrome**을 사용합니다. 따라서 Chrome을 공식 설치 프로그램으로 준비하면 별도의 `npx playwright install` 과정은 필요하지 않습니다. 환경 확인 명령인 `npm run doctor`는 Chrome을 잠깐 실행해 확인한 뒤 닫으며, 대한항공에는 접속하지 않습니다. [Playwright의 Chrome 사용 안내](https://playwright.dev/docs/browsers#google-chrome--microsoft-edge)

## 두 버튼의 차이

| 버튼 | 동작 |
| --- | --- |
| 마일리지 좌석 조회 | 선택한 노선·월의 공개 현황을 불러옵니다. 최근 12시간 이내 저장 결과가 있으면 재사용합니다. |
| 선택한 날짜로 대한항공 열기 | 버튼을 누를 때 새 Chrome 창을 열고, 공식 공개 달력에 노선·편도/왕복·월·좌석 등급·날짜를 입력합니다. |

자동 입력은 기존 Chrome의 로그인 상태를 가져오지 않는 별도 창에서 진행됩니다. 완료 후 창이 열린 상태로 남으므로 직접 확인할 수 있습니다. 로그인·예약·결제는 자동으로 진행하지 않습니다. 좌석 등급은 **공개 달력의 필터**에 적용되며, 이후 예매 화면까지 같은 조건이 전달되는 기능은 아닙니다.

전체로 조회한 날짜를 열면 대한항공 달력에도 일반석·프리미엄석·프레스티지석의 **보너스 필터 3개**를 적용합니다. 일등석·좌석 승급 필터는 적용하지 않습니다.

## 조회 결과를 읽는 방법

- **좌석 표시가 있는 날짜:** 공개 달력에 선택한 등급의 보너스 좌석 표시가 있는 날짜 수입니다. `0일`이면 공개 현황에 해당 표시가 없다는 뜻이며 조회 실패나 실시간 매진을 뜻하지 않습니다. 확인한 월 전체 날짜 수도 따로 표시합니다.
- **여행 기간에 맞는 날짜:** 왕복의 오는 편에서 선택한 가는 날과 최소 여행 기간에 맞는 날짜 수입니다. 이달의 전체 보너스 표시 날짜 수와 다를 수 있습니다.
- **대한항공 공개 현황 기준:** 대한항공이 공개 현황의 기준으로 표시한 시각입니다.
- **현황을 가져온 시각:** 이 프로그램이 해당 결과를 가져온 시각입니다. 대한항공 공개 현황 기준과 다를 수 있습니다.
- **이번에 가져온 결과 / 이전에 가져온 결과:** 새로 조회한 구간과 저장된 결과를 재사용한 구간을 구분합니다. 조회 버튼을 눌러도 최근 12시간 이내 결과라면 재사용합니다.

조회가 완료되지 않은 구간은 `좌석 현황 미확인`으로 안내합니다. 새 조회에 실패해도 이전에 저장한 결과를 삭제하지 않으며, 이전 결과를 보여주는 경우 별도로 안내합니다.

## 지원 범위

- 이번 달을 제외하고, 대한항공의 향후 360일 범위 안에 **전체 날짜가 포함되는 미래 월**을 조회합니다. 화면에서 선택 가능한 범위를 확인해 주세요.
- 왕복은 가는 편과 오는 편을 각각 조회합니다. 두 날짜에 공개 표식이 있다고 해서 해당 왕복 조합의 예약이 보장되지는 않습니다.
- 화면의 ‘최소 여행 기간’은 **두 항공편의 출발일 간격**입니다. 도착 시각과 시차를 반영한 실제 체류 기간은 아닙니다.
- 모든 목적지·모든 월의 일괄 검색, 정기 알림, 카카오톡·이메일 발송은 제공하지 않습니다.
- 사이트의 화면 구조가 바뀌거나 접속이 제한되면 자동 처리가 중단될 수 있습니다. 접근 제한을 우회하거나 자동으로 재시도하지 않습니다.

프로그램은 `127.0.0.1`에서만 실행됩니다. 이 저장소를 GitHub에 올려도 조회 서비스가 자동으로 배포되지는 않습니다. 데이터 이용 범위는 대한항공의 정책을 확인해야 하며, 로컬 실행이나 비로그인 접근 자체가 이용 허가를 의미하지는 않습니다.

## 저장되는 파일

| 경로 | 용도 |
| --- | --- |
| `data/local/` | 노선·월별 조회 결과와 접근 제한 상태 |
| `artifacts/airline-handoff/` | 자동 입력 실패 시 공개 화면의 제한된 진단 자료 |
| `data/`, `artifacts/` | 별도 CLI 실행 결과와 개발용 검증 자료 |

위 폴더와 `.env`, 인증 세션 파일, 로그, `node_modules/`는 `.gitignore`에 포함되어 있습니다. **조회 데이터는 저장소에 포함되지 않으며**, 다른 컴퓨터에서는 직접 조회해야 합니다. 비밀번호·로그인 쿠키를 저장소에 넣을 필요가 없습니다.

## 개발 및 문서

```sh
npm test
npm run typecheck
npm run build
python3 -m unittest discover -s tests -p 'test_*.py'
```

테스트는 저장된 테스트 자료와 모의 응답을 사용하며 항공사에 접속하지 않습니다. SAS의 브라우저 처리 회귀 검사는 Chrome 설치 후 `node --import tsx --test tests/sas-search.browser.mjs`로 실행합니다. 이 검사도 모든 요청을 테스트 화면으로 대체합니다. 일반적인 앱 실행에는 빌드 명령이 필요하지 않습니다.

Windows에서는 위 명령의 `python3`를 `python` 또는 `py -3`로 바꾸세요. PowerShell에서는 `npm.cmd`를 사용하면 npm의 PowerShell 실행 정책 오류를 피할 수 있습니다.

GitHub Actions의 Windows·macOS 환경에서 설치, 자동 테스트, 타입 검사와 빌드가 모두 통과했습니다. Windows에서는 한글 경로의 실행 파일과 하위 프로세스 종료도 확인했습니다. [검사 결과 보기](https://github.com/we-insub/Korean_air/actions/runs/34083177862)

실제 대한항공 조회까지 확인한 환경은 macOS이며, Windows 실기기에서의 항공사 조회는 아직 검증하지 않았습니다. 자동 테스트는 항공사에 접속하지 않습니다.

### 로그인과 월별 조회

1. 서버 실행 후 **http://127.0.0.1:8765/** 에 접속합니다. HTML 파일을 직접 열면 조회할 수 없습니다.
2. 프로그램을 선택하고 **로그인·조회 창 열기**를 누릅니다.
3. 필요한 프로그램만 앱이 연 Chrome에서 직접 로그인합니다. 대한항공·스카이팀은 대한항공 로그인을 공유합니다. 아시아나·스타얼라이언스도 같은 프로필을 사용합니다. SAS는 별도 조회용 프로필을 사용합니다.
4. 로그인 후 **로그인 완료·확인**을 누릅니다. SAS는 같은 로그인 세션에서 제휴 보너스 검색 화면으로 연결합니다. 로그인 필요와 검색 화면 미준비를 구분해 안내하며, 이 버튼은 월별 조회를 시작하지 않습니다. 이어서 출발·도착 공항, 가는 달, 좌석 등급, 편도·왕복을 선택합니다. 왕복이면 오는 달도 선택합니다.
5. **선택한 월 새로 조회**를 누릅니다. SAS는 로그인한 Chrome의 최대 6개 탭에서 날짜별 검색을 동시에 진행하며, 고정 대기 없이 확인된 날짜부터 표시합니다. 아시아나는 월별 공개 달력을 가져옵니다. 스카이팀·스타얼라이언스도 선택한 월의 검색을 최대 6개 탭에서 동시에 처리합니다. 날짜 사이의 30초 고정 대기는 제거했습니다. 결과 화면에는 실제 경과 시간을 표시합니다. 결과는 도착하는 대로 표시합니다.
6. **조회 중단**으로 멈출 수 있습니다. 확인한 날짜는 유지하고 나머지는 미조회로 표시합니다.

대한항공·아시아나의 공개 달력은 실시간 재고가 아닙니다. 항공사 기준 시각과 가져온 시각을 구분해서 확인하세요. 그 밖의 검색 결과도 조회한 시점 이후 바뀔 수 있습니다. 검색 실패·접속 제한·미조회는 좌석 없음으로 처리하지 않습니다. 예상과 다른 화면은 수집을 중단하므로 공식 사이트 개편에 따라 수정이 필요할 수 있습니다.

설치된 Chrome과 Playwright를 사용하며 확장 프로그램이나 개발자 모드 설정은 필요하지 않습니다. 평소 쓰는 Chrome의 로그인 정보를 복사하지 않습니다. 로그인 만료나 보안 확인이 나오면 조회용 창에서 직접 처리해 주세요. 조회 중 해당 창의 조건을 바꾸면 결과 조건 검증에 실패할 수 있습니다.

대한항공·스카이팀·아시아나·스타얼라이언스 조회용 Chrome은 서버를 종료해도 열어 둡니다. 서버를 다시 실행하면 같은 조회용 창에 연결하므로 서버 재시작만으로 로그인 창을 새로 만들지 않습니다. Chrome을 직접 닫거나 항공사 세션이 만료되면 다시 로그인해야 할 수 있습니다.

**GitHub에는 프로그램만 배포합니다.** 사용자는 각자 설치하고 본인 계정으로 새로 조회합니다. 개발자의 계정이나 조회 데이터를 배포하지 않습니다. 표시되지 않은 좌석 수·필요 마일리지는 추정하지 않습니다.

- SAS 좌석 결과: `data/local/sas.sqlite3`
- 월별 조회 결과: `data/local/month-results/`
- SAS 로그인 유지: `data/sas-chrome-profile/`
- 대한항공·스카이팀·아시아나·스타얼라이언스 로그인 유지: `data/partner-chrome-profile/`

모두 Git에서 제외됩니다. Chrome 프로필은 로그인 유지 데이터를 포함하므로 공유하지 마세요. 이 앱은 좌석 결과에 계정 이름·비밀번호·마일리지 잔액을 저장하지 않습니다.

### 확인한 범위

2026-09-10 macOS에서 SAS AMS→CDG 일별 검색, 아시아나 ICN→NRT 2026년 11월 공개 달력 30일, 스타얼라이언스 ICN→NRT 일별 검색, 스카이팀 ICN↔NRT 왕복 검색과 오는 편 항공편 수집을 확인했습니다. 월별 계획·오류·중단 처리는 자동 검사합니다. 모든 월·노선의 전수 조회나 Windows의 항공사 실접속까지 검증한 것은 아닙니다.

스카이팀은 재로그인 후 서버를 재시작해도 같은 Chrome 세션으로 검색되는 것을 확인했습니다. 로컬 월별 화면에서 ICN→NRT의 2026년 11월 1·2일을 일반석·비즈니스·일등석 순서로 실제 조회하고, 결과 표시·상세 선택 유지·중단 후 나머지 56일 미조회 표시까지 검증했습니다. 오는 날 기준은 11월 30일이며, 이 검증에서 월 전체를 조회한 것은 아닙니다. 좁은 Chrome 창에서 추가로 필요한 날짜·등급의 ‘선택’ 버튼도 처리합니다.

SAS 월별 조회는 요청한 날짜의 항공사 응답이 완료된 뒤 화면 조건과 대조합니다. 초기 병렬 방식에서 측정한 약 50초는 반복 검증 중 조건 불일치가 발견돼 완료 성능의 근거로 사용하지 않습니다. 최신 검증은 접속 제한으로 중단되어 월 전체 완료 시간은 검증되지 않았습니다. 조회용 탭은 완료 후 닫고 로그인 창은 유지합니다. 접속 제한이나 로그인 만료가 나오면 새 날짜 검색을 멈추며, 미확인 날짜를 좌석 없음으로 표시하지 않습니다.

월별 조회 방식: 대한항공과 아시아나는 공식 월간 달력을 가져옵니다. SAS·스카이팀·스타얼라이언스는 공식 날짜별 검색을 최대 6개씩 동시에 실행해 월별 달력으로 모읍니다. 사용자는 월을 한 번 선택하지만, 항공사에 보내는 요청이 월간 요청 한 건으로 바뀌는 것은 아닙니다. 5개 프로그램 모두 1분 이내 완료를 보장하지 않습니다.

현재 프로그램별 실조회 소요 시간과 미확인 결과는 [월간 조회 검증 기록](docs/monthly-query-verification.md)에 정리했습니다.
