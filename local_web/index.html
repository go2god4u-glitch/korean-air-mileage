      9시 예매 대기 오픈런

      두 항공사 모두 매일 오전 9시에 예매 가능 범위의 마지막 날짜를 엽니다 (대한항공 360일 뒤 · 아시아나 364일 뒤). 타려는 날짜를 넣으면 그날 9시에 맞춰 대기하다가, 자리가 나오는 즉시 좌석까지 선택한 예매 화면을 띄워드려요. 결제만 직접 하시면 됩니다.

      자기 전에 이 세 가지만

      1. 계정별로 로그인 — 아래 이 계정으로 로그인 열기를 누르면 그 계정 전용 Chrome 창이 열려요. 창 위쪽 파란 띠에 계정 1·계정 2가 적혀 있으니 보고 구분하세요. 계정마다 창이 따로라 두 계정을 동시에 로그인해 둘 수 있어요.
      2. 대기 등록 — 항공사·계정·노선·타려는 날짜를 넣고 9시에 잡기 추가. 여러 건을 동시에 걸 수 있어요.
      3. 전원 연결 — 대기 중엔 맥이 잠들지 않게 자동으로 잡아두는데, 배터리만으로는 유지되지 않아요.

      나머지는 알아서 합니다 — 로그인 세션 8분마다 갱신 · 9시 90초 전 조회 화면 미리 준비 · 정각에 동시 발사 · 좌석까지 선택. 결제만 직접 하시면 돼요. 이 맥이 켜져 있고 프로그램이 실행 중이어야 합니다.
